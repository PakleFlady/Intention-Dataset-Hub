# Changelog

## Unreleased research preview

- Added XMEI-dataset, Intend to Move (I2M), DeceptionDecoded, MIntRec and MIntRec2.0, with original sources, input/output examples, access gaps and annotation-provenance notes checked on 2026-11-02.
- Grouped the two MIntRec releases as one dataset family; retained distinct taxonomies and release records. No unreviewed benchmark scores were added.

- Added a generated, snapshot-scoped best-value overview with explicit gaps for datasets lacking verified results; dataset pages now show their verified metric values.

- Added source-linked input/output examples to all dataset pages, with author-published visual previews where available and clear distinction between illustrative examples and exact source records.
- Replaced overview separators that had rendered as replacement characters after upload; validation now rejects U+FFFD and invalid UTF-8.
- Corrected LOKI access from open to request after rechecking the official access conditions.
- Established a source-backed dataset catalog, protocol model, validators, generated Markdown, and contributor workflow.
- Seed coverage and comparative result coverage are being built to the v0.1 release gates. The README reports actual verified counts.
- Open gaps: independent second-pass review of every seed entry; broader direct HRI and daily-intention coverage; more protocol-matched independent methods. See [coverage notes](docs/coverage.md).

The public repository URL is recorded in `CITATION.cff`. No DOI has been assigned.
